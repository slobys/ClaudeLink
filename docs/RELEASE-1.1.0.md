Claude Link 1.1.0 默认打开官方 Claude 桌面应用的 Code 页面，并提供在线更新。

### 安装

下载 ClaudeLink-Setup-1.1.0.exe。退出旧版后覆盖安装，节点、订阅和偏好保留。1.0.x 请先手动安装此版一次，之后可在软件内更新。

### 更新内容

- 桌面客户端与 CLI 分开设置，默认桌面客户端；自动发现普通安装版及 MSIX 商店版。
- 桌面模式使用 TUN，打开官方 Code 页面并交由 Claude 确认项目文件夹；不会再把 CLI 路径当作客户端。
- 启动自动检查新版本，提供下载进度、取消、安装并重启；可关闭自动检查或手动检查。
- 更新清单使用 ECDSA 签名，安装包验证大小与 SHA-256；升级前恢复临时环境并等待旧进程正常退出。
- 保留 Chrome 优先的专用核对窗口、语言设置、节点订阅及独立网络检测明细。
- 修复管理员助手导致其他安装目录被误判为正在使用的问题。

### 验证

Windows x64：31 项核心断言、12 份官方内核配置、60 项集成检查、5 项界面检查、6 项安装升级检查通过；已检测并打开本机官方 Claude 桌面应用。实际账号授权及节点可用性由用户自己的客户端和网络决定。

Portable 为便携包，Source 提供可构建源码、许可证及内核对应源码。此项目为独立启动器，非 Anthropic 或 SagerNet 官方产品。
