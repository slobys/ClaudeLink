# Claude Link 网络启动器 v1.1.2

适用 Windows 10/11 x64。内置 sing-box 1.14.4，无需另外打开 FlClash 或 v2rayN。

## 安装

1. 双击 ClaudeLink-Setup-1.1.2.exe，点击安装。
2. 安装到当前用户的 %LOCALAPPDATA%\Programs\ClaudeLink，可从桌面或开始菜单打开。
3. 安装包包含运行环境和代理内核；使用 TUN 或临时系统环境功能时才请求管理员权限。
4. 便携版解压后运行 ClaudeNetworkLauncher.exe。单独复制发布目录内的该 EXE 也可运行。

## 第一次使用

1. 在「节点管理」选择添加/导入节点，粘贴分享链接或手动填写；支持从剪贴板或本地文件导入。
2. 或在「订阅管理」添加订阅名称和地址，程序会下载并在本机解析。下载或解析失败时保留旧节点。
3. 在工作台选择节点与项目文件夹，点击「准备并打开 Claude 桌面客户端」。默认使用 TUN，允许本次管理员授权。
4. 启动器查找官方 Claude 桌面应用（含 MSIX 商店版），打开其 Code 页面，并由 Claude 确认项目文件夹。桌面路径可留空；.local/bin/claude.exe 是 CLI，不应填入桌面路径。
5. 需要命令行时，在环境设置把启动方式改为「Claude Code 命令行（CLI）」，旧 CLI 路径会保留，届时在独立终端运行。桌面应用下载：https://claude.com/download ；CLI 安装：https://code.claude.com/docs/en/setup 。

## 节点与订阅格式

支持 VLESS（TLS/Reality）、VMess、Trojan、Shadowsocks、Hysteria2、TUIC、SOCKS5、HTTP/HTTPS、AnyTLS 的常见配置。

支持分享链接、Base64 分享链接订阅、含 proxies 列表的 Clash YAML、sing-box outbound JSON。

传输支持 TCP、WebSocket、gRPC、HTTPUpgrade 和导入格式可表达的 HTTP/2。不支持的条目会单独报告。当前不支持 SSR、XHTTP/KCP、Shadowsocks 插件、多端口跳跃和仅含外部 proxy-providers 的配置。

## 两种连接方式

- CLI 进程代理：仅监听 127.0.0.1:17890；为启动的 Claude 终端设置 HTTP_PROXY、HTTPS_PROXY、NO_PROXY 和所选语言环境。不更改 Windows 系统代理。CLI 模式也可选择 TUN。
- 桌面客户端使用 TUN：默认选中并标明必需，连接时允许 UAC。内核建立 ClaudeLink 虚拟网卡，接管全机外网流量，覆盖已运行的客户端及其 Code 进程，局域网直连。关闭其他代理客户端的 TUN，可减少路由冲突。桌面模式不把 CLI 的进程环境变量当作桌面网络已生效的证据。

## 环境与检查

环境设置可选择临时关闭活动物理网卡 IPv6、根据 Claude 出口参考时区临时调整 Windows 时区。这两项影响整台电脑，修改前记录原状态，退出后尝试恢复。进程语言标识不会修改 Windows 显示语言或输入法。Claude 桌面应用的显示语言由官方客户端自身管理。

1.2.1 首次安装已预选 TUN、严格预检、临时关闭 IPv6、临时匹配时区，语言为 en-US，浏览器自动选择且优先 Chrome；已有配置保留原来的明确选择。安装本身不改网络，连接并完成系统授权后才执行相应设置。

「沿用 v1.3 严格预检」检查 API 和 Claude 网页可达、三个出口为相同 IPv4、参考国家为美国、TUN 已启用、活动物理网卡 IPv6 已关闭、系统时区匹配。这是原启动器的自定义策略，不代表账号授权检查。未获取的数据标为未验证；API 401 仅表示 HTTPS 可达，Claude 网页 403 会单独标为网页检查未通过。确认启动前会列出具体未通过项目。

登录页检测地址为 `https://claude.ai/login`，专用浏览器也会打开此地址。程序的自动请求没有普通 Chrome 的登录状态和网页交互；HTTP 403 表示该请求被拒绝，不等于账号被停用或 Chrome 无法打开。启动确认窗默认「返回检查」，选择继续仍会保留原来的未通过结果。

「打开专用核对浏览器」默认优先 Chrome，环境设置可明确选择 Chrome 或 Edge。先选择「CLI 与专用核对浏览器语言」（美国英语为 en-US）并保存，再从工作台打开。每次创建新的独立配置，使用当前会话 HTTP 代理，同时打开语言核对页和网络检查页。语言核对页直接读取 navigator.language、navigator.languages 和 Intl 的实际值。

语言只应用于新启动的 Claude 终端和专用核对窗口。已有普通 Chrome 标签页会继续使用其原语言；请在启动器新打开的专用窗口里核对。普通 Chrome 的书签、扩展、登录状态、语言偏好和 Windows 显示语言均保持原样。语言设置不会验证账户资格或保证第三方网站的判断结果。

## 退出与恢复

- 桌面模式不会因客户端的启动进程退出而断网；使用完点击「断开」或托盘「退出并恢复环境」。不会强行关闭 Claude 桌面窗口或项目。
- CLI 正常结束后自动断开并恢复本次临时环境。
- 运行会话时关闭主窗口会进入系统托盘，继续维护连接。
- 仅连接未启动 Claude 时，可点击断开；托盘「退出并恢复环境」可停止会话后退出。
- 主界面意外退出时，后台宿主尝试停止内核并恢复。宿主被强杀时，Windows 作业对象终止其内核，系统环境恢复记录留待下次处理。
- 发现未完成恢复记录会阻止新连接。点击「恢复临时设置」，按需允许 UAC。断电/重启后也需重新打开程序处理。

## 配置与卸载

配置保存在 %LOCALAPPDATA%\ClaudeNetworkLauncher\settings.dat，使用当前 Windows 用户 DPAPI 加密。运行时内核配置短暂为本地明文，正常退出和下次启动清理失效会话配置。不要共享数据目录。

运行记录保存操作摘要，不记录订阅地址、密码和完整链接。更新订阅访问你的订阅服务；网络检查访问 ipify、Cloudflare、Claude 和 IP 地理服务。

从 Windows「已安装的应用」卸载；卸载保留节点、订阅与恢复记录。更新或卸载前先从托盘退出启动器。

## 在线更新

1.1.1 起默认启动时检查 GitHub 正式版本，有新版时顶部显示「立即更新」。下载时有进度和取消按钮，通过 ECDSA 签名清单及 SHA-256 校验后，点击「安装并重启」。环境设置也可手动检查或关闭自动检查。离线时检查失败不会阻止使用。

安装前保存偏好、停止本启动器的网络会话并恢复临时设置；安装器等待旧进程正常退出后覆盖安装，再重新打开。节点、订阅、项目和 Claude 桌面窗口不会被删除。CLI 仍在工作时需先正常退出 CLI。便携版使用此功能会安装到当前用户目录。

1.0.x 尚无在线更新，请先手动安装 1.1.1 一次。下载：https://github.com/slobys/ClaudeLink/releases/latest 。

此安装包未使用商业 Authenticode 证书；更新清单有独立发布签名。首次联网效果取决于实际节点、订阅和本机网络，详见验证记录。
